# چوب‌خط — نمونه اولیه اندروید

پروژه Android Java بدون وابستگی جانبی؛ شش بخش آماده توسعه، فضای کاری پویا، منوی انتخاب قابلیت‌ها، صندوق پیام نمایشی، تنظیمات ارتباط، و چت **متنی واقعی** از طریق AvalAI.

## ساخت در GitHub
1. محتویات این پوشه را در **ریشه یک مخزن تازه** قرار دهید و به شاخه `main` ارسال کنید. اگر مخزن قبلی دارید، پیش از جایگزینی از آن نسخه پشتیبان بگیرید؛ این بسته لزوماً با فایل‌های قبلی سازگار نیست.
2. تب **Actions** → گردش‌کار **Build Choobkhat APK** → **Run workflow** (یا push به main).
3. پس از اجرای موفق، از بخش **Artifacts** فایل `choobkhat-debug-apk` را بگیرید. این فایل ZIP خروجی اکشن است و درون آن `app-debug.apk` قرار دارد.
4. روی گوشی نصب کنید. این نسخه **debug** برای آزمایش است، نه انتشار عمومی.

## استفاده از چت
- چرخ‌دنده → تنظیمات ارتباط → «API مستقیم AvalAI».
- آدرس پیش‌فرض `https://api.avalai.ir/v1` است؛ نام مدل پیش‌فرض `gpt-5.4-mini` را متناسب با مدل‌های فعال حساب‌تان تغییر دهید.
- **کلید را فقط در اپ روی دستگاه خودتان وارد کنید؛ در مخزن، Issues یا گفتگو منتشر نکنید.** کلید به کمک Android Keystore روی دستگاه رمزگذاری می‌شود.
- چراغ سبز یعنی درخواست `/models` موفق بوده؛ **دلیل بر فعال بودن مدل منتخب یا موفقیت همه درخواست‌های چت نیست**.
- در چت یک پیام بفرستید؛ درخواست POST به `/chat/completions` ارسال می‌شود، پاسخ نمایش داده می‌شود و تاریخچه همین نشست به درخواست‌های بعدی ضمیمه می‌شود. تاریخچه پس از بسته‌شدن اپ یا «گفتگوی جدید» پاک می‌شود.

## محدودیت‌های آگاهانه
- بخش سرور داخلی فعلاً **فقط گزینه رابط کاربری** است و هنوز اتصال واقعی ندارد؛ برای آن قرارداد API و معماری احراز هویت لازم است.
- شش قابلیت دیگر نمایشی‌اند و به پایگاه داده، پیامک، پیام‌رسان یا زمان‌بند متصل نیستند. صندوق و صوت هم نمایشی هستند. لاگین عمداً وجود ندارد.
- تماس مستقیم با API از داخل APK برای نمونه شخصی قابل استفاده است، اما در محصول چندکاربره بهتر است کلید مرکزی پشت سرور امن خودتان بماند. در این پروژه کاربران کلید شخصی خودشان را وارد می‌کنند.
- اپ روی Android 8 به بالا هدف‌گذاری شده است؛ ساخت نهایی روی GitHub Actions باید تأیید شود. در محیط سازنده، Android SDK/Gradle برای اجرای build در دسترس نبود و **APK در این بسته نیست**.

مستندات: https://docs.avalai.org/en/api-reference/introduction

## نسخه ۰٫۲: چت چندرسانه‌ای آزمایشی

- «مکالمه صوتی»: تشخیص گفتار دستگاه (در صورت نصب سرویس تشخیص گفتار) → ارسال متن به AvalAI → خواندن پاسخ با TextToSpeech اندروید. مکالمه پیوسته و تمام‌دوطرفه/Realtime نیست؛ برای نوبت بعد دوباره دکمه را بزنید. ممکن است تشخیص گفتار توسط سرویس گوشی پردازش شود.
- «ضبط صدا»: بار اول مجوز میکروفون می‌خواهد؛ با ضربه دوم ضبط متوقف شده و فایل صوتی به `/audio/transcriptions` ارسال می‌شود. متن استخراج‌شده قبل از ارسال به مدل برای ویرایش نمایش داده می‌شود. مدل پیش‌فرض `groq.whisper-large-v3` است و به دسترسی حساب AvalAI به این مدل نیاز دارد.
- «عکس/فایل/صدا»: عکس به JPEG فشرده و به‌صورت `image_url` داده‌ای به مدل انتخابی ارسال می‌شود؛ **مدل انتخابی باید از ورودی تصویری پشتیبانی کند**. فایل متنی UTF-8، CSV و JSON تا ۲ مگابایت خوانده می‌شود و حداکثر ۴۰هزار کاراکتر آن وارد پیام می‌شود. فایل صوتی انتخابی ابتدا پیاده‌سازی می‌شود. PDF و Word و دیگر فایل‌های دودویی فعلاً پشتیبانی نمی‌شوند و پیام واضح نمایش داده می‌شود.
- کلید API در کد یا مخزن قرار نگیرد؛ مانند نسخه قبل در حافظه امن دستگاه تنظیم می‌شود. محدودیت‌های اندازه فایل برای جلوگیری از مصرف حافظه و هزینه ناخواسته اعمال شده‌اند.
- این پروژه هنوز در یک محیط دارای Android SDK کامپایل/روی دستگاه تست نشده است؛ ZIP فقط از نظر یکپارچگی آرشیو بررسی شده است. پس از آپلود، نتیجه GitHub Actions را بررسی کنید.
